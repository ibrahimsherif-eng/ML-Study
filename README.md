## Learning Philosophy

The approach followed in this repository is:

1. Understand the mathematics behind the algorithm
2. Build intuition for what the algorithm is actually doing
3. Implement the algorithm from scratch
4. Compare against standard library implementations (e.g., scikit-learn)
5. Combine theory and practice to reinforce understanding
